---
name: Workflow stage meaning
description: How to interpret progress stages when reports have gaps or need more information.
---

The missing-information check counts as complete once the prototype has identified gaps, even if those gaps remain unresolved. A request for more information is still part of human review; approval and rejection both count as completed human decisions.

**Why:** The tracker describes which review activities occurred, not whether all report details have been supplied. Treating identified gaps as unfinished extraction would obscure that the report is awaiting a person.

**How to apply:** When adding new report statuses or progress displays, keep the distinction between detecting missing details and resolving them, and reserve the final stage for an explicit human decision.
