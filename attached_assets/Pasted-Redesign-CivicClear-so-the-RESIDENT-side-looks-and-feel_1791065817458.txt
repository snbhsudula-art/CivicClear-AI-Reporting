Redesign CivicClear so the RESIDENT side looks and feels like a modern mobile app rather than a traditional website.

IMPORTANT: Keep all existing functionality, data, TRACE fixes, AI Analysis, and staff review features working exactly as they currently do.

RESIDENT MOBILE APP:
- Make the resident experience mobile-first and app-like.
- Use a full-screen mobile layout with rounded cards, clean spacing, large touch-friendly buttons, and simple icons.
- Avoid the appearance of a desktop website squeezed onto a phone.
- Minimize traditional website elements such as large navigation bars, excessive empty space, and desktop-style forms.
- Use a compact app header with the CivicClear logo/name.
- Add a bottom navigation bar with:
  Home
  Make a Report
  My Report

MAKE A REPORT:

Step 1: What happened?
Step 2: Where did you notice it?
Step 3: How urgent is it?
Step 4: Review your report
Step 5: Submit

Each step should have one clear purpose and large touch-friendly controls.

LOCATION:

"Where did you notice the issue?"
Helper text:
"Enter the address if you know it. You can also provide a nearby intersection, landmark, or bus stop."

MY REPORT:

✓ Report Submitted
✓ In Progress
● Human Review
○ Decision

HOME:

DESIGN:

- Mobile-first
- Clean cards
- Rounded corners
- Large buttons
- Clear typography
- Minimal clutter
- Easy one-handed navigation
- Smooth transitions between steps
- Responsive on phone, tablet, and desktop
